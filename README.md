# Projeto Democratização de Dados do Governo

Projeto colaborativo para facilitar o acesso e a compreensão de dados públicos governamentais.

## Objetivo

Tornar dados governamentais mais acessíveis, organizados e compreensíveis para a população.

## Escopo inicial

O projeto começará com dados legislativos, com foco inicial no estado de São Paulo.

## Fontes de dados

- Câmara dos Deputados
- Senado Federal
