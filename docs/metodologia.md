# Metodologia

Este documento registra os procedimentos utilizados para coleta, organização, tratamento e análise dos dados do projeto.

## Etapas previstas

1. Identificação das fontes de dados.
2. Coleta dos dados.
3. Armazenamento dos dados brutos.
4. Limpeza e tratamento.
5. Transformação dos dados para análise.
6. Análise e definição das métricas.
7. Disponibilização dos resultados.

A metodologia será detalhada e atualizada conforme o projeto avançar e as bases de dados forem definidas.
