# Dicionário de Dados

Este documento descreve os campos e variáveis utilizados nas bases de dados do projeto.

O dicionário será atualizado conforme as bases de dados forem definidas, coletadas e tratadas.

## Bases previstas

Inicialmente, o projeto considera dados provenientes de:

- Câmara dos Deputados
- Senado Federal

## Estrutura

Para cada base utilizada, serão documentados:

- nome do campo
- descrição
- tipo de dado
- fonte
- tratamento realizado
- observações
